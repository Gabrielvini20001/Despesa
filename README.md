Uma aplicação web interativa e responsiva para gerenciamento e organização de despesas pessoais, rodando totalmente no navegador.

---https://gabrielvini20001.github.io/Despesa/

## 📱 Sobre o Projeto
O **Despesa** é uma ferramenta simples e intuitiva para controle financeiro. Toda a lógica de armazenamento e manipulação dos dados é feita diretamente no lado do cliente (Client-side), utilizando recursos modernos do JavaScript.

## 🚀 Funcionalidades
- **Fluxo de Caixa:** Cadastro de receitas e despesas com descrição e valor.
- **Armazenamento Local:** Os dados ficam salvos no navegador do usuário (via `LocalStorage`), ou seja, você não perde as informações ao atualizar a página.
- **Interface Responsiva:** Adaptado para telas de computadores, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização moderna (Grid/Flexbox) e design responsivo.
- **JavaScript (ES6+):** Manipulação do DOM, cálculo dos saldos e persistência de dados.
